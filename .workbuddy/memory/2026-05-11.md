## DockerConverter.py 全面优化重构

- **消除重复代码**：提取 `_flush_buffer` + `_process_and_register` 辅助函数，原来三处相同的命令处理逻辑合并为一处。
- **健壮性增强**：
  - `_safe_next()` 统一防御参数索引越界，给出清晰错误信息
  - `--name` 同时写入 `container_name` 字段
  - 网络去重（相同网络名只加一次）
  - `--memory-swap` 支持
  - `shlex.split` 异常捕获
  - 文件读取 `OSError` 完整捕获
  - 返回 `bool` 值，失败时 `sys.exit(1)`
- **字段顺序**：`_reorder_service_config()` 按 FIELD_ORDER 排序：`image → container_name → ports → environment → volumes → restart → 其他`
- **日志美化**：`_info / _warn / _error / _ok / _sep` 统一输出格式，`════` 分隔线区分段落
- **移除 `version: '3.8'`**：现代 compose 规范已废弃该字段
- **示例命令**：从 `__main__` 中移至模块常量 `_SAMPLE_COMMANDS`，逻辑更清晰

## DockerConverter 改造为 Web UI + 标准包结构

- **标准 src layout 包结构**：`src/docker_converter/__init__.py` + `core.py` + `app.py`
